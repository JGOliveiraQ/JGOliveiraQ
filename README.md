## `// 03 —` PROJETOS

<br/>

**01 — Instagram Monitor**

Sistema completo para monitoramento automático de perfis do Instagram de clientes de uma agência de marketing. Coleta seguidores e posts diariamente, processa crescimento semanal/mensal e exibe tudo num dashboard com login individualizado por cliente.

- Scraping autenticado com sessão persistida
- Roteamento via **rede Tor (SOCKS5)** com rotação automática de circuito
- **GitHub Actions CI/CD** agendado diariamente às 11h, sem intervenção humana
- Credenciais como **GitHub Secrets**, restauradas em runtime
- Integração com **Google Sheets API** como banco de dados de séries temporais
- Flask multi-tenant + API REST com análise de crescimento 7d/30d

**02 — GMB Reviews AI**

Plataforma fullstack que conecta ao **Google My Business API** para gerenciar avaliações e gera respostas profissionais automaticamente com IA — rodando um LLM local, sem custo de API externa.

- Autenticação via **Google OAuth2** com escopo `business.manage`
- Backend **Node.js + Express** + frontend **Next.js** (React + TypeScript)
- IA com **Ollama (LLaMA 3)** local — zero custo de inference
- Prompt engineering contextualizado com nota + comentário do cliente
